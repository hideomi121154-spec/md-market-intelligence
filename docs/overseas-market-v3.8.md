# v3.8 海外の中古車需要・輸出動向

## 目的とデータ範囲
日本国内の掲載台数だけではなく、輸出需要を中古車需給分析に併記するための補助パネル。国内AA価格の予測や買い推奨は行わない。

- 2025年1月〜12月、2026年1月〜9月の月別輸出台数、2026年1〜9月の国別上位10、2026年9月の普通車・ハイブリッド・EV・軽のカテゴリ別輸出先ランキング。
- 2026年10月29日発表の日本の普通貿易統計を、JUMV.NETがe-Stat統計から独自集計した公開表から採録。元データは財務省貿易統計 https://www.customs.go.jp/toukei/ 。二次出典 https://jumv.net/basic_knowledge_usedcar_export/export_statistics/statistics と https://jumv.net/ 。
- JUMV.NETとJUMVEA（日本中古車輸出業協同組合）は別の主体です。集計範囲・計上基準等の違いに注意し、JUMVEAの2025年170万8,604台と本スナップショット2025年171万4,279台を混同しない。
- 2026年10〜12月は欠損（月次0台ではない）。data/overseas-export-snapshot.jsonに固定したスナップショットであり、月次最新値の自動取得・自動更新は未実装。
- 国別は仕向け地ベースで、最終需要地やメーカー・車種別輸出台数ではない。
- 車両カテゴリ別順位はサイト分類。車種名の同定ではない。

## 実装内容
「市場」タブの折りたたみ可能な「海外中古車需要・輸出動向」。月次2025/26比較、前年同月比、前月比、国別累計ランキング、カテゴリー別の輸出先上位を表示する。日銀・経産省・財務省への公式リンクを併記。

ドル円と規制・関税・船積み・海外需要のニュースはユーザーが出典付きで手入力する端末内ノート。JSON手動バックアップと追加復元、衝突IDは拒否。独立localStorageキー md-market-overseas-notes-v1 を使い、既存の109件、仕入れ計算、個人車両、故障情報には書込みしない。

## 制限
- 為替と輸出台数は異なる頻度で更新される。日次レートに月次数値を日次として混ぜない。
- 新規データは公表元・利用条件を確認して差し替える。無許可の自動スクレイピングはしない。
- ロシア等への輸出規制は排気量・ハイブリッド等の条件や最終仕向け地が重要。経産省の最新情報で確認する。
- 単純な輸出台数と国内掲載在庫を比率化して需要指数と呼ばない。個別AA価格・車種別輸出需要・成約率を推定したと主張しない。
