# MD MARKET 市場インテリジェンス（5段階・初期実装）

## 目的

公式市場統計と公開データの**観測された変化**を起点に仮説・反証・事後点検までつなげる。AIで将来価格を断定したり、ユーザーの個別価格記録を無断変更したりしない。

入口：iPhone PWA → **市場** → **市場インテリジェンス｜5段階分析**（初期状態は折りたたみ）。

## 機能

1. **異変レーダー**：USS月次の出品台数、成約台数、成約率、平均落札価格を読み込む。連続した前月との比較、成約率↓×単価↑、出品増加率＞成約増加率を発見する。既存 `MDMarketWarning.evaluate` の前年同月ベースの警戒閾値は変えない。
2. **将来供給シナリオ**：2021～2025年の軽乗用車上位15車名、登録乗用車上位50車名を使い、販売年＋3/5/7年のコホートを表示する。ユーザーが仮定した流通率だけ乗じる。出品・買替率の実績ではない。未収録年は**データなし**。2021年登録乗用車の二次資料は区別する。既存の「残クレ満了車｜将来供給シミュレーター」に遷移できる。
3. **地域比較**：求人の実数を前年同月または前月と比較、人口移動は同月の転入・転出実数と前年同月純移動の変化を確認。47都道府県。**自動車需要予測値ではない**。
4. **仮説探索**：市場乖離・地域の組み合わせ・将来の車両年齢コホートに対して、観測根拠、仮説、代替仮説、追加データ、反証方法を提示する**決定論的ルールエンジン**。外部LLM/APIの自律調査ではない。
5. **事後検証**：警戒判定時の同月数値だけで当月を評価し、実際の翌月USS平均価格と後から並べる。連続する月だけを採用し、未公表の翌月は予測扱いで追加しない。月次サンプルが少ない間は的中率を出さない。

## 制限

- USS全体平均の価格は車種・年式・品質構成未調整。車種別中古車相場の断定・仕入上限の推定には使わない。
- 年次の**新車販売台数**は中古車への流通割合そのものではなく、手入力の仮定率は実証値ではない。
- 求人はハローワークの受理地別、人口は国内転入出実数。車の購入人数を測るものではない。
- カーセンサー・グーネットなどから許諾のないデータの巡回はしない。
- 過去データが7か月程度の間はバックテストの評価・学習のための標本が足りない。運用上は探査指標であって実証予測モデルではない。
- すべての公開データはネットワーク利用可能時に新しく取得し、オフラインではPWA保存済みの資料を使う。収録のない項目は空として表示する。

## テスト

```bash
node tests/test_market_intelligence.cjs
node tests/test_market_warning.cjs
node tests/test_residual_maturity.cjs
node tests/test_population_migration.cjs
```

今後のデータ拡張で実務的な予測評価に進むには、複数年のUSS同定義月次統計、使用許諾のある車種別成約価格・台数・出品構成、地域別保有・登録・流通数、車種別買い替え実績が必要。
