# MD MARKET v2.9 — USS市場全体の下落早期警戒（試験版）

## 目的と対象
既存の公式USS月次自動更新データ（data/uss_monthly.json、schema_version:1）から、需給の緩みを価格下落前に気付くための**警戒ルール**を表示する。無料の公式集計のみ利用。車種別の落札価格データ・確率モデルは利用していない。

## データフロー
- GitHub ActionsがUSS公式IRから検証してJSON保存。既存のuss.jsが検証・読み込み、成功時にmdmarket:uss-dataイベントを送出。
- market-warning.jsはその確定済みデータから各月を独立に評価する。オフラインではUSSモジュールの既存キャッシュ経由で評価。取得不可のとき「判定不可」で止める。
- 月次データのchecked_at_utcは**取得確認日時**であり、公式発表日時やアラート発生日時とは異なる。
- 車種別個人データは収集・統合・アップロードしない。

## 監視ルール（検証前の仮設定）
USSのoffered_yoy_pctとsold_yoy_pctは**前年比指数**。115.0は+15.0%の意味。
- 出品前年同月増加率 >= +5%
- 出品増加率 − 成約増加率 >= +4.0ポイント
- 成約率の前年同月との差 <= −2.0ポイント
3条件で「警戒：高」、2条件で「警戒：注意」、0〜1条件で「警戒条件なし」。欠測/不正データは「判定不可」（安全とは判断しない）。

**警戒＝将来の価格下落が確定したという意味ではない。** 月次の需給異常を優先して見るだけ。月の最後に集計・公表されるデータなので月中のリアルタイム先読みはできない。閾値は過去データで最適化・検証した値ではなく、確率・信頼度・30/60日先の値下がり率は出さない。

## 過去月のリプレイ（事後検証）
月を選ぶとその月の出品・成約・成約率のみで警戒判定。同じデータ内に**連続する翌月**がある場合だけ、翌月の平均成約単価の前月比を「事後検証」として表示する。判定ロジックには将来月の価格を使用しない。

例：2026年7月 出品前年比+15.0%、成約前年比+10.8%、差4.2ポイント、成約率前年差−2.4ポイント → 警戒：高。翌8月の平均成約単価は134.5万円→124.8万円（約−7.2%）。この1件だけで予測精度を主張しない。

## 制限と次の検証
- USS平均価格は取引車種や品質の構成比が変わるため、同一仕様車の価格下落率ではない。
- 警戒レベルはUSS市場全体用。個別車種・地域・グレードの仕入れ上限、売価、販売日数の提案には使用禁止。
- 直近のJSONは当期月を最大12か月のみ保存。十分なバックテスト・偽陽性率の算出に不足。
- 今後は過去の公表日時を含む長期時系列を独立保存して当時利用可能だった情報だけで時点再現し、翌月/翌々月の下落検出率・誤警報率・リードタイムを測る。
- 次段階の車種別予測には、ライセンス・利用規約を満たす個別相場・在庫・掲載履歴等が必要。新車販売台数を中古車の実落札値として扱わない。
