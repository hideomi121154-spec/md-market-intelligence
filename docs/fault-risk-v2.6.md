# 故障・修理情報ノート v2.6

対象: MD MARKET 個人向けPWA。既存の価格/在庫/IndexedDBは一切書き換えない独立機能です。

- 車名＋型式ごとの症状・故障部位・報告区分・確認状況・距離・修理費・原典URLを端末内localStorageに保存。
- E12 / HE12 / E13などを別型式として扱う。排ガス記号(DBA-, DAA-など)はマッチング時だけ除外。
- 国交省不具合申告 / リコール / メーカー公式ページへのリンクを提供。ページで車名・型式を利用者自身が入力する。
- SNS/口コミ等は原典URL付きで利用者が記録。無断スクレイピング、メーカーの整備記録API接続、全件自動収集は実装していない。
- 国交省への申告は「リコール確定」ではない。現場観察を保存しても故障率、車種間の頻度比較には変換しない。
- 修理費や入札上限の計算は**利用者が入力した金額の単純差額のみ**。自動査定や推奨買い価格を意味しない。
- 同一事例の重複投稿、分母、仕様差、改修済みの区別など、統計上の不確実性がある。
- 端末ストレージが壊れた場合は**保存を停止して上書きしない**。既存の個人向け価格バックアップJSONとは別に故障メモのJSONをコピーして保管する。
- 公開GitHubには個別のメモ・個人情報を保存しない。車台番号・ナンバー・氏名・連絡先は入力禁止。
- 将来: 利用許諾が確認できる公的データの正規取り込み経路、ソース照合、型式辞書、重複排除、走行距離条件の予測検証を追加する。
