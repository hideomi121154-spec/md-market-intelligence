# 全車種対応の故障関連記事調査（v2.8）
- ユーザーはメーカー（任意）・車種・型式（任意）を入力する。事前登録のない車種も検索可能。
- ブラウザから公開ニュース検索API GDELT DOC2 ArticleList（直近3か月）へ問い合わせ、車種・型式と一致する**記事の見出し**を部品・症状カテゴリ別に集計する。
- GDELT記事検索はSNS/X/みんカラや整備ブログの網羅検索ではない。得られたのは関連**記事件数**であり、故障数・リコール数・故障率ではない。
- 日本語記事/型式が見出しに明記されない場合は候補から除く。これにより誤混入を抑える一方、取りこぼしが多くなりうる。
- GDELTが利用不可・CORS/レート制限/通信障害のときはエラーを表示。Web検索・X検索・国交省への外部リンクで追加調査できる。
- 個別の国交省申告の分類集計は、合法的に出典確認・集計した車種のみ表示。E12等の事前集計を「全車種」へ外挿しない。
- 外部検索に送信するのはメーカー・車種・型式の検索語。個人の価格記録、車台番号、電話番号等は送らない。
- 将来SNSをアプリ内に取り込む場合は、利用権限とAPI・バックエンドでのトークン秘匿が必要。現状、SNSのライブ検索・全車種の故障率分析は未実装。
- 過去の故障メモlocalStorage、価格ノート、109件の記録は移行・削除・上書きしない。
