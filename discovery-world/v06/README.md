# DISCOVERY WORLD v0.6 — 法則変化を発見して観測方法を選び直す

## 目的

原始世界を知らないAIの発見を研究するための、**仮想物理モデルの変化検出ベンチマーク**です。2026年までの科学技術を知るLLMや汎用AIではありません。実験データに基づいて測定候補を選ぶ探索アルゴリズムです。

## プレイ

[GitHub Pagesで実験する](https://hideomi121154-spec.github.io/md-market-intelligence/discovery-world/v06/)

1. 世界番号を選ぶ（初期値2026）。
2. 「1世界で実験」を押す。
3. 世界が変更された際の検出結果、4種類の予測誤差、変更前後の測定手順を確認する。
4. 「30世界で再現性を検証」を押す。
5. 「JSONファイルを共有・保存」または「JSONをダウンロード」で結果を取得。iPhoneからは共有→「ファイル」に保存→ChatGPTの添付から送信。直接送るなら「結果全文をコピー」でテキストを貼り付ける。
6. CSVは表計算向けの要約。**JSONには1世界の観測経過、学習前後の測定、予測と実測、30世界の個別記録が含まれる。**

## 実験設計

- 4個の潜在変数による人間が作った合成世界。外側の探索処理には潜在変数を引き渡さない。
- 3チャネルの観測結果を予測する。
- 変更前は3個の潜在変数が重要、変更後は第4変数が強く影響する設定。
- 6素材×3前処理×2配置×2時間×2読取 = 144測定プロトコル。
- 変更前の32環境で校正し、16環境で3測定プロトコルを選定。
- 変化なしの10環境と法則変更後10環境で従来モデルの予測誤差を比較。変化判定は予め定めた `max(0.006, 6 × 初期検証誤差)` を超えるか。
- 変更後の32環境で校正し、18環境で新たな4プロトコルを選定。**これは新環境で出力の正解例が得られるという条件付きの実験**。
- 比較するのは「凍結モデル」「同じ3センサーで再学習」「4センサーを再選択」「ランダムな4センサー（12回の平均）」であり、変更後の未使用32環境でのみ採点する。
- 学習・検証・保留テストに使う環境IDは区別。テストの正解は測定手順の選択に使わない。
- 実験中の測定の総回数をカウント。多くの候補を探索するAIと、無作為選択の比較群では測定コストが等しくない。
- `seed` を固定すれば再現できる。一般化の評価は種の異なる30世界で確認する。

## 固定シード2026の例

開発ソースZIPを展開し、`node test.cjs` を実行して再計算してください。

- 変化の検出：成功
- 変化なしの誤警報：なし
- 変更前モデルをそのまま使う： MSE 約0.04870
- 同じセンサーで新世界を再学習：MSE 約0.04712
- 観測手順を再選択：MSE 約0.00010
- 無作為な4手順：MSE 約0.00073（12回平均）
- 計測数：116108センサー読取り（候補探索を含む）

## 科学的な限界

これは完全に**設計済みの物理法則・設計済みの観測器候補**に基づく教育・研究用デモです。AIは新しい計測原理をゼロから発明しません。法則変更も研究者があらかじめ入れたもので、無限に開かれた現実の未知概念を発見した証拠ではありません。結果は限られた模擬世界内の性能であり、現実社会への適用を示しません。
