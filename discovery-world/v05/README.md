# DISCOVERY WORLD v0.5 — 「何を測るか」を見つけるAIの検証

## 研究課題
AIに「湿度」や「測るべき隠れた特徴」を教えず、観測手順を素材×前処理×置き方×時間×読み取り方式という原始的な操作から構成させる。特定の物理概念を言葉で与えなくても、観測結果が未来の未知環境での予測を改善するか検証する。

## 被験世界
これは現実の物理法則を再現した環境ではなく、3種類の潜在変数から3種類の現象が生じるよう設計した教育用のブラックボックス世界。AIは潜在変数名・値を直接利用しない。測定手順で得た結果を線形予測モデルに加え、汎化するか調べる。

## 評価方法
- 校正用の環境28件で関係を学ぶ
- 観測方法選択用の環境16件で測定手順を選ぶ
- 完全に別の環境32件は手順を選び終わるまで評価しない（最終評価）
- 測定なし、3手順を自動合成、無作為3手順の24回平均を比較
- 3回の段階的な観測手順選択を通じ、各段階で候補を検証用環境に照らし、最も予測を改善する手順を選ぶ
- 30世界の結果は独立した乱数種で再現性を測る

## 原理と重要な限界
- AIが選ぶ手順は、人間が実装した素材や基本操作の有限な組み合わせであり、完全に新しい物理計測器の発明ではない。
- 3つの現象A〜Cを予測するという目的は開発者が設定している。人間にない研究課題をゼロから発見したわけではない。
- 対照群の無作為3手順と、AIの144候補×3段階にわたる測定手順探索は、探索・校正の実験コストが等しくない。この比較から実験効率の優越は主張できない。
- 評価対象の未知環境は**同じ隠れた法則で状態のみ変えた環境**。物理的な法則そのものを変更した他世界への転移能力は未検証。
- 簡易的な最小二乗法による予測改善を測定しているだけで、因果法則の同定、現実の未知物理法則、人間が想像できない発明の証明ではない。
