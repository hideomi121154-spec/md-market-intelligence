# DISCOVERY WORLD v0.4 — 開かれた仮説空間の実験

## 狙い
v0.3は世界の法則が必ず既存16候補に入っていた。本版は、答えをその外に置き、AIに次の研究段階を選ばせる。

1. **有限仮説**: 初期16個のBoolean法則を観測データに照合
2. **式の合成**: 候補がなくなったら、新しい特徴組合せの式を構築・照合
3. **測定軸の追加**: 既存3特徴で説明不能になったら未知特徴Xの測定を要請
4. **再予測**: 新しい特徴を取り込み、未実験の16組を予測

## 実験の仕様
- 12種類の素材、3つの観測チャネル
- 素材の組み合わせ66通りのうち、50通りのみ実験候補
- 残り16通りの観測値はAIの学習・実験選択に使用しない
- 16候補の固定探索 / 文法に基づく式生成のみ / 式生成+未知特徴X測定 / 無作為探索+同じ式生成機能の4方式を同時比較
- 予測の評価は分類精度とBrier score
- 追加の測定操作は環境の提供するセンサーを使うものであり、AIが測定器そのものを発明してはいない

## 再現方法
ブラウザで [v0.4](https://hideomi121154-spec.github.io/md-market-intelligence/discovery-world/v04/) を開き、世界番号を2026として24手実行。別世界の再現性は「30世界 × 24手を比較する」を使う。

## 固定テストの結果
- seed=2026 / 24手：新しいAIの未知条件正答率97.9% / 初期16候補固定50.0%
- seed=1701から導出した30世界 / 24手：拡張AI 99.93% / 固定16候補47.92% / 式生成のみ78.82% / 無作為探索+拡張99.10%
- 同30世界 / 8手：拡張AI84.65% / 固定16候補50.63% / 式生成のみ81.53% / 無作為探索+拡張82.85%

**注意**: これは意図的に作られた有限のブール世界の教材実験。世界の真の法則は既知のAND/OR/XOR/NOTで表せ、式生成の文法も人間が設計済み。現実の未知物理法則の発見や、人間にない認知概念の自律的創造を証明しない。

## 次の検証課題
- 正解の法則を、式生成の文法にも含まない状態で未知性を検出できるか
- センサーや道具の構造からAIが測定方法を考案できるか
- 候補の優先順位における情報獲得費用と実験費用を最適化できるか
- 未知の世界の生成方法を固定した評価を超えて一般化できるか
